# 🚀 PROYECTO: EcoOfertasBot - Sistema de Ingresos Pasivos

## 🎯 Objetivo Principal
Crear un activo digital automatizado utilizando Python que rastree ofertas reales en internet y las presente al público para generar comisiones a través de marketing de afiliados. El objetivo es generar ingresos pasivos mediante el tráfico orgánico y la automatización.

## ✅ Implementaciones Completadas (Versión 2.0 - Producción)

### 1. El Motor de Búsqueda (Scraper Profesional)
- **Arquitectura Genérica**: Implementado un `GenericScraper` basado en selectores CSS. Ahora se pueden añadir nuevas tiendas sin escribir código nuevo, solo configurando selectores.
- **Base Robusta**: Implementada la clase `BaseScraper` con manejo de User-Agents, timeouts y limpieza automática de precios (conversión de texto a float).
- **Soporte de Imágenes**: El bot ahora extrae las URLs de las imágenes de los productos para una web visualmente atractiva.

### 2. El Cerebro (Lógica de Negocio & Monetización)
- **Sistema de Memoria**: `StorageManager` dedicado que utiliza `ofertas.json` para evitar duplicados y gestionar el estado de las ofertas.
- **Monetización Dinámica**: Implementado `AffiliateService` con el patrón Strategy. Soporta formatos específicos para Amazon, AliExpress y otros proveedores genéricos.
- **Seguridad de Secretos**: Integración con `.env` para proteger IDs de afiliados y claves API, siguiendo estándares de seguridad.

### 3. La Vitrina (Frontend Moderno)
- **Diseño Premium**: Implementada la web usando **Tailwind CSS**. Diseño responsivo, moderno y optimizado para conversión.
- **Filtros Interactivos**: Añadido un sistema de filtrado por categorías mediante JavaScript en el frontend, permitiendo al usuario navegar la web sin recargar la página.
- **Galería Visual**: Implementación de tarjetas de producto con imágenes reales, precios destacados y botones de llamada a la acción (CTA).

### 4. Infraestructura y Automatización (Cloud Ready)
- **Orquestador Central**: Implementado `main.py` que coordina el flujo completo: Scrape $\rightarrow$ Filtro $\rightarrow$ Afiliación $\rightarrow$ Publicación.
- **Despliegue Automatizado**: Configurado **GitHub Actions** para ejecutar el bot cada 6 horas automáticamente en la nube.
- **Hosting Gratuito**: Implementado el despliegue automático a **GitHub Pages**, convirtiendo el proyecto en una web pública accesible desde cualquier lugar.
- **Estándares de Código**: Todo el proyecto ha sido refactorizado siguiendo PEP 8, con anotaciones de tipo (Type Hinting) y logging profesional.
